## About me

- 🍜 **Currently building Yum or Nah**, a swipe-based recipe discovery app ("Tinder for recipes"). Version 1 was Flutter + Spring Boot; the rewrite is React Native + Expo on the front end and Node.js, Express, Prisma, Postgres and MinIO on the back end.
- 🥽 Built an **Apple Vision Pro + iPad app** in Swift that teaches the Platonic solids in AR and VR, used as the instrument for a learning research study.
- 🤖 Building a **local RAG pipeline**: ChromaDB vector search + BM25, fused with reciprocal rank fusion, answered by an Ollama model behind a FastAPI server, plus LoRA fine-tuning experiments.
- ☕ Lots of **Java**: Spring Boot services (a URL shortener, a Twilio SMS scheduler), a WebSocket chat room, data structures work and CLI apps.
- 🐍 Plenty of **Python** too: Streamlit web apps, Google API automation and handy desktop utilities.
- ⌨️ I live in the terminal: Neovim, LazyVim and a hand-rolled CLI IDE config.
